feat: 상태 페이지에 파비콘과 머리글 로고 마크를 추가한다

상태 페이지 탭이 브라우저 기본 문서 아이콘으로만 표시되고 머리글에
제품을 식별할 시각 요소가 없었다. `lib/brand.js`를 로고 SVG 문자열의
단일 출처로 두고, `assets/icon.svg`(Armory 카탈로그용 사본)와
`<link rel="icon">`(base64 data URI) · 머리글 `.brand` 마크를
그 출처에서 파생시켜 표기가 서로 갈라질 수 없게 했다.

파비콘은 단독 SVG 문서라 xmlns 선언이 필요한데, 기존 테스트가 렌더된
HTML에 "http://" 문자열 0개를 요구한다 — base64 data URI로 실어
두 요구를 동시에 지켰다. 직전 라운드가 추가했던 "렌더된 HTML 전체에
claude 0개" 기준은 013이 엔진 범위를 화면에 반드시 표시하는 동결
동작과 논리적으로 양립 불가능했으므로, 013 생존 확인과 016 자신의
추가분(파비콘·마크·CSS)에 한정한 claude 0건 증명으로 대체했다.
계약 버전(1.5.0)과 기존 432개 테스트는 전혀 건드리지 않았다.
