# 010 — 사용량을 한눈에 보는 웹 페이지

## 배경

지금 사용량을 보려면 `curl http://127.0.0.1:3210/api/status` 로 JSON 을 읽거나, Foreman 이
연결되기를 기다려야 한다. **브라우저로 열어 바로 보는 창구가 없다.**

이 제품의 목적은 "지금 토큰을 써도 되는지, 얼마나 남았는지"를 알려주는 것이다.
007·008 이 그 데이터를 계약대로 내주게 만들었으니, 사람이 보는 표면 하나를 얹는다.

⚠️ **Foreman 과 역할이 겹치지 않나?** 겹치는 부분이 있다. 다만 Foreman 은 **대장간 가동 상태**를
보는 곳이고 Quaestor 는 **대장간 옆에 붙어 있는 장치**다(`PROJECT_INTENT.md`). 그리고
Foreman 이 죽어 있어도 이 페이지는 보여야 한다 — 감시자가 살아 있는 한.

## Project Type

제품(Quaestor) 진화. **ADDITIVE · never-brick.**
🔒 기존 API 응답·판정 로직은 **한 글자도 바꾸지 않는다.** 페이지는 `/api/status` 의 **소비자**다.

## Scope

### 1. `GET /` 가 HTML 을 낸다

지금은 JSON 404 다. 여기에 페이지를 붙인다. `/api/*` 경로는 **그대로 둔다.**

- 🔒 **[SPEC] 정적 파일 서빙 경로를 만들지 말 것.** 요청 경로로 파일 경로를 조립하면
  디렉토리 탈출이 생긴다. **알려진 자산 하나만** 내보낸다(경로 조립 없음, `..` 처리 불필요).
- 🔒 **[SPEC] 인증 게이트는 지금 순서 그대로.** 토큰이 설정돼 있으면 페이지도 401 이다.
  API 는 막고 화면만 여는 예외를 만들지 않는다.
- `Content-Type: text/html; charset=utf-8`

### 2. 페이지가 보여줄 것

**`/api/status` 만 소비한다.** 🔒 **[SPEC] 브라우저에서 판정을 다시 하지 말 것** —
임계 비교·허용 여부·신선도는 전부 서버가 이미 냈다. 페이지는 **그리기만** 한다.

| 영역 | 내용 |
|---|---|
| 큰 배지 | `allowance.allowed` → **사용 가능** / **차단됨** / **모름** |
| 사용량 | 세션 % · 주간 % (숫자 + 남은 여유 headroom) |
| 임계값 | `usage.thresholds` — 지금 적용 중인 값 |
| 마지막 측정 | `measured_at` + 경과 시간, `stale` 이면 강조 |
| STOP | 있으면 source/reason |
| 실패 | 측정 실패 중이면 `kind` · `hint` |

### 3. 🔒 화면이 거짓말하지 않는다 — 이 NNN 의 핵심

**[SPEC] `allowance.allowed === null` 이면 "모름"으로 그린다. 🔒 초록·"사용 가능" 금지.**

이게 실패하면 이 NNN 은 실패다. 이유는 이 제품의 역사 그 자체다 —
프로세스가 살아 있다는 이유로 초록불을 켰다면 28일 침묵을 아무도 몰랐을 것이고,
`/api/health` 와 `/api/status` 를 분리한 것도 같은 이유였다. **화면에서 그걸 되돌리지 않는다.**

**[SPEC] `usage.stale === true` 면 숫자가 낡았음이 눈에 보여야 한다.**
경과 시간(`age_sec`)을 함께 보여주고, 신선한 값과 **시각적으로 구분**한다.
🔒 28일 전 숫자를 현재 값처럼 그리면 실패다.

**[SPEC] 값이 `null` 이면 `0` 이나 `-` 로 뭉개지 말고 "측정 없음"으로 표시한다.**
`0%` 는 "여유 만점"이라는 정반대 뜻이 된다.

### 4. 의존성 0 · 오프라인 동작

- 🔒 **[SPEC] 외부 요청 0.** CDN 스크립트·웹폰트·원격 이미지 금지.
  loopback 전용 페이지이고 네트워크가 없어도 떠야 한다. CSS·JS 는 인라인
- 새 npm 패키지 금지(현재 의존성은 puppeteer 하나뿐)
- 자동 새로고침: `/api/status` 를 주기적으로 다시 부른다(기본 30초).
  🔒 GET 은 부작용이 없으므로(007 조항) 폴링해도 측정을 유발하지 않는다

### 5. 🔒 never-brick

**[SPEC] 페이지 서빙이 실패해도 감시 루프는 계속 돈다.** 004 의 조항 그대로다.
차단기가 화면 때문에 죽으면 안 된다.

## Acceptance (hermetic)

- [SPEC] 실제 포트를 열고 `GET /` → **200** + `Content-Type` 이 `text/html`
- [SPEC] 🔒 `allowed: null` 스냅샷으로 렌더한 HTML 에 "사용 가능" 류 긍정 문구가 **없고**
  "모름"에 해당하는 표시가 있다. 🔒 초록 상태 클래스가 붙지 않는다
- [SPEC] `stale: true` 스냅샷의 HTML 에 경과 시간이 나타나고 신선한 경우와 **다른 표시**가 붙는다
- [SPEC] `session_pct: null` 스냅샷의 HTML 에 `0%` 가 **나타나지 않는다**
- [SPEC] HTML 전체에 `http://` · `https://` 로 시작하는 **외부 리소스 참조가 0건**
  (`src=`/`href=`/`@import`/`fetch(` 대상). 상대 경로 `/api/status` 만 허용
- [SPEC] `/api/health` · `/api/status` 응답이 010 전과 **완전히 동일**하다(회귀 없음)
- [SPEC] `GET /api/does-not-exist` 는 여전히 **JSON 404** 다(HTML 로 바뀌지 않는다)
- [SPEC] 🔒 경로 조립이 없다 — `GET /../../etc/hosts` 류가 파일을 노출하지 않고 JSON 404 다
- [SPEC] 토큰이 설정된 상태에서 `GET /` 는 **401**(화면만 여는 예외 없음)
- [SPEC] 페이지 HTML·API 응답 어디에도 비밀이 없다(토큰·프로필 경로·쿠키·계정)
- [SPEC] 🔒 **경계 검증**: 실제 포트를 열고 `fetch('/')` 로 받은 **실제 HTML 문자열**을 검사한다
  (템플릿 함수 반환값만 보면 라우팅·헤더가 검증되지 않는다)

## Out of Scope

- 🔒 LAN 바인딩 — 이 페이지도 **loopback 전용**이다. 다른 PC 에서 보려면 별도 결정
- 임계값 편집·STOP 걸기/풀기 등 **쓰기 동작** — 읽기 전용 페이지다.
  🔒 `POST /api/stop` 을 의도적으로 비워둔 결정과 같은 이유
- 히스토리 차트·시계열 저장
- Foreman 쪽 화면

## USER_GATE

- 브라우저로 `http://127.0.0.1:3210` 을 열어 확인
- 🔒 **측정이 죽어 있는 지금 상태에서 열었을 때 "모름"으로 보여야 한다.**
  여기서 초록불이나 "사용 가능"이 보이면 실패다 — 이 제품이 겪은 실패를 화면이 재현하는 것이다
